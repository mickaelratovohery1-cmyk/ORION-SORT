# Intelligence artificielle — Responsable : Alphonse

Classes : plastique, métal, papier, carton et inconnu/absence d'objet.

Le sujet demande un dataset construit par l'équipe. Prévoir au moins 150 images par classe comme point de départ et vérifier les exigences exactes du document de concours. Photographier plusieurs objets, angles, éclairages et fonds. Séparer les données d'entraînement, validation et test sans fuite entre ensembles.

Pipeline : collecte → contrôle/annotation → séparation des données → entraînement (ex. MobileNetV2 en transfert d'apprentissage) → évaluation (accuracy, précision, rappel, matrice de confusion) → export du modèle.

Le dépôt ne contient pas de modèle entraîné.
